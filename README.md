# Tours à travers les âges — version web

Jeu d'exploration de Tours à différentes époques (Flutter + Flame), avec restitutions 3D
(collégiale Saint-Martin et cathédrale Saint-Gatien en 1785, Caesarodunum vers 150, castrum vers 385)
et page de réalité virtuelle (`vr/index.html?model=<id>`).

Version construite (`flutter build web --release --base-href /tours_epoques/`) ; les sources du jeu
ne sont pas dans ce dépôt. Données : © contributeurs OpenStreetMap (ODbL), base Mérimée
(Licence Ouverte 2.0), Wikidata (CC0), photos Wikimedia Commons (auteurs et licences affichés dans le jeu),
courts extraits cités des Bulletins de la Société archéologique de Touraine (Gallica). Toutes les
ressources sont listées dans le jeu et dans `docs/ressources.md` du projet.
